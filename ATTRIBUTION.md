# Provenance and licenses

This labeling project started by reviewing the video and conferencing filters in
[Traffic Refinery](https://github.com/traffic-refinery/traffic-refinery) at commit
`dcb2eba9464a4a002168478ad5550e845bfc53c3`. The inherited Traffic Refinery engine,
build tooling and unrelated configuration files have been removed from this
fork's current tree. Labeling rules, research and Python hostname tools now live
at the repository root.

The upstream [Apache 2.0 license](LICENSE.md) is retained. Pinned
v2fly/domain-list-community snapshots retain their MIT license in each evidence
directory. nDPI evidence consists of extracted domain facts with revision and
line references; no full nDPI implementation is included. Per-rule source IDs,
upstream links, snapshot licenses and evidence manifests document the inputs.
